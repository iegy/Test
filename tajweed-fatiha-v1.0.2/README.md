# مُعلّم الفاتحة — Native Android v2.0.1

تطبيق Android Native باللغة العربية لتدريب المستخدم على تلاوة سورة الفاتحة (حفص عن عاصم) محليًا قدر الإمكان، بدون حسابات أو Backend أو API مدفوع.

## الوظائف المنفذة

- اختيار آية من الفاتحة أو قراءة السورة كاملة.
- مرجع صوتي مدمج للشيخ محمد صديق المنشاوي من ملف Wikimedia Commons المصنف Public Domain.
- استبعاد الاستعاذة تلقائيًا من المرجع وتقسيم الآيات السبع من الفواصل الصوتية.
- زر استماع للمرجع يعمل Native.
- تسجيل الميكروفون عبر `AudioRecord` إلى PCM/WAV.
- تشغيل تسجيل المستخدم عبر `AudioTrack`.
- إدراج WAV/MP3/M4A/OGG من Android Document Picker وفك الصوت عبر `MediaCodec`.
- إدراج مرجع صوتي بديل وحفظه محليًا.
- VAD وفحص طول التسجيل والضوضاء والتشبع.
- محاذاة صوتية للنص المعروف + مقارنة زمنية/طيفية محافظة.
- قياس المد نسبةً إلى المرجع بعد تعويض سرعة القراءة، مع Confidence.
- نتيجة لكل كلمة: PASS / REVIEW / FAIL / UNDECIDABLE.
- سجل محلي لآخر 20 محاولة.
- لا إذن INTERNET ولا رفع لتسجيلات المستخدم.

## مهم بخصوص الدقة

هذه النسخة لا تدعي أنها نموذج Phoneme/Quran-ASR متعلم كامل، ولا تدعي تشخيص دقائق المخارج والصفات تشخيصًا قطعيًا. الفونيمات المعروضة هي النطق المتوقع نظريًا، بينما الحكم الصوتي الحالي يعتمد على known-text alignment وخصائص صوتية وتوقيت وثقة. عند انخفاض الثقة تكون النتيجة `UNDECIDABLE` بدل اختراع خطأ.

## الاختبارات

يوجد Python reference pipeline في:

`python/reference_pipeline.py`

وفي GitHub Actions لا يتم إصدار الـAPK إلا بعد نجاح بوابة Regression التي تتحقق من:

- تقسيم الفاتحة 7/7 آيات.
- رفض الصمت.
- اجتياز المرجع الصحيح لاختبار المد المرجعي.
- اكتشاف القطع الشديد في كل آية.
- عدم رفض تغيّر السرعة المعقول 0.80× و1.25× لمجرد السرعة.

راجع:
- `reports/V2_REGRESSION_REPORT.md`
- `reports/MODEL_DATASET_AUDIO_LICENSE_REPORT.md`
- `reports/P0_DECISION_MATRIX.md`
- `PROJECT_STATE.md`

## البناء

المتطلبات: JDK 17 + Android SDK 35.

```bash
./gradlew assembleDebug
```

الناتج القياسي:

`app/build/outputs/apk/debug/app-debug.apk`

الـCI يحمّل المرجع Public Domain أثناء البناء ويضعه داخل APK، ثم يفحص الـLauncher والـasset والتوقيع ويخرج APK + Source ZIP + تقارير التحقق.

## الخصوصية

- لا حسابات، Firebase، Analytics، إعلانات أو Tracking.
- تسجيلات المستخدم لا تُرفع إلى خادم.
- المرجع المخصص وسجل المحاولات يبقيان في مساحة التطبيق المحلية.
- حذف بيانات التطبيق يمسح هذه البيانات المحلية.
