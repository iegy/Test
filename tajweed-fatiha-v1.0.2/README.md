# تجويد الفاتحة — Android Prototype V1

نموذج Android حقيقي، عربي أولًا، لتسجيل تلاوة سورة الفاتحة وتحليلها محليًا. لا يحتاج حسابًا أو خادمًا أو API مدفوعًا، ولا يرفع التسجيلات أو المراجع الصوتية.

## ما يعمل الآن

- اختيار أي آية من الفاتحة أو السورة كاملة.
- تسجيل التلاوة من الميكروفون ومعالجتها على الجهاز.
- رفض الصمت والتسجيل القصير والضوضاء الشديدة بدل إعطاء نتيجة وهمية.
- Voice Activity Detection ومحاذاة زمنية على مستوى الكلمات.
- تلاوة مرجعية كاملة للفاتحة مدمجة بترخيص CC0، مع تقسيم محلي لمقاطع الآيات.
- محاذاة DTW مع المرجع المدمج أو مع مرجع اختياري يستورده المستخدم.
- اكتشاف النقص الزمني الواضح مقارنةً بالمرجع.
- قياس تجريبي للمد نسبةً إلى وحدة زمنية محلية قريبة من الحركة، وليس مقارنةً بميلي ثانية ثابتة لقارئ واحد.
- نتائج خضراء/صفراء/حمراء/رمادية مبنية على الثقة.
- تفاصيل لكل كلمة، الفونيمات المتوقعة، الزمن، قواعد المد، والتشخيص الفني.
- حفظ ملخص آخر 20 محاولة محليًا.
- حفظ المرجع المستورد محليًا عبر IndexedDB.
- تحليل ملف صوتي جاهز للاختبار، وإعادة الاستماع إلى تسجيل المستخدم.
- خطة أحكام تعليمية لكل آية تشمل المد، اللام الشمسية والقمرية، الإظهار، والتفخيم حيث ينطبق.

## التثبيت المباشر

1. انقل ملف `Tajweed_AlFatiha_v1.0.2_installable.apk` إلى هاتف Android.
2. افتح الملف من تطبيق الملفات.
3. إذا طلب Android الإذن، فعّل «السماح من هذا المصدر» لتطبيق الملفات فقط.
4. اضغط «تثبيت»، ثم افتح «تجويد الفاتحة».
5. وافق على إذن الميكروفون عند بدء أول تسجيل.

احذف النسختين التجريبيتين 1.0.0 و1.0.1 أولًا؛ النسخة 1.0.2 مبنية وموقعة من السورس بأدوات Android القياسية، ولذلك يختلف مفتاح الاختبار عن مفتاح النسخ المرقّعة السابقة.

التطبيق لا يطلب حسابًا ولا يرسل الصوت إلى الإنترنت، ولا يطلب إذن INTERNET. التلاوة المرجعية موجودة داخل APK.

## البناء من السورس

المتطلبات: JDK 17 وAndroid SDK 35. Gradle Wrapper مضمّن.

```bash
./gradlew assembleDebug
```

على Windows:

```powershell
gradlew.bat assembleDebug
```

الناتج القياسي:

`app/build/outputs/apk/debug/app-debug.apk`

لإصدار Release للنشر، أضف signingConfig خاصًا بك ولا تستخدم مفتاح اختبار. مشروع Kotlin يستهدف API 35، وعند بنائه بأدوات Android القياسية يحصل على توقيع APK v2+ تلقائيًا.

## الاختبارات

```bash
node tests/core.test.js
```

راجع `reports/TEST_REPORT.md` و`reports/KNOWN_LIMITATIONS.md` قبل أي تجربة ميدانية أو ادعاء دقة.

## البنية

- `MainActivity.kt`: غلاف Android محلي وإدارة إذن الميكروفون.
- `assets/core.js`: المعالجة الصوتية، VAD، DTW، المحاذاة، المد، والثقة.
- `assets/app.js`: التسجيل، التخزين المحلي، الاستيراد، وعرض النتائج.
- `engine/EngineContracts.kt`: عقود مستقرة لاستبدال المحرك لاحقًا بـONNX/TFLite دون ربط قواعد التجويد بالنموذج.
- `engine/MaddRule.kt`: قرار مد حتمي نسبةً إلى سرعة القارئ.

## الخصوصية

- لا حسابات، لا Firebase، لا تحليلات، لا إعلانات، ولا تتبع.
- التسجيل الحالي يبقى في الذاكرة أثناء التحليل ثم يُترك لجمع الذاكرة؛ لا يُحفظ كملف.
- ملخصات المحاولات والمراجع المستوردة تبقى في مساحة التطبيق المحلية.
- حذف بيانات التطبيق من إعدادات Android يمسح المحاولات والمراجع.
